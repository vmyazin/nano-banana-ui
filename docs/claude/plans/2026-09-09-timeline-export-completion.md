## Outcome

Done. One deviation worth recording: the export filename is generated by a
module-scope `exportFilename()` rather than inline in `runExport`, because the
purity lint reads the component body as render scope and rejects a `Date.now()`
there even inside an async handler.

Smoke-tested on :3141 with a real 8s encode — the panel ended on
"Exported timeline-export-1788963784403.mp4 · 2.4 MB · 8s · with audio", the file
downloaded, and Save to library added one pinned 2.4 MB video that showed up in
the clip rail ready to be placed on a timeline again.
